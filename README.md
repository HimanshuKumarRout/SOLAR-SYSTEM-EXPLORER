## 🌟 Overview

**Solar System Explorer** is an interactive and visually immersive application that enables users to explore our cosmic neighborhood.

Built for **students, educators, and astronomy enthusiasts**, it combines **3D visualization** with real-time data to deliver an engaging educational experience.

---

## 🚀 Key Features

- 🪐 **Explore Planets & Moons** – Detailed profiles of planets and their satellites  
- 🌐 **Interactive 3D Model** – Rotate, zoom, and navigate the solar system  
- 🛰️ **Live Data Integration** – Real-time planetary positions and data  
- 📚 **Educational Content** – Facts, properties, and discovery history  
- 🔍 **Search & Filter** – Quickly find celestial bodies  
- 📱 **Responsive Design** – Works on desktop & mobile  

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **3D Engine:** Three.js  
- **Backend (Optional):** Node.js, Express.js  
- **API:** NASA APIs
